## 原生 IP 到底指什么，跟“独享 IP”不是一回事

原生 IP 有两层含义，缺一层都不算数。

第一层是归属地一致：机房在洛杉矶，分到的 IP 在 ARIN 这类注册机构的记录里归属地也是洛杉矶。第二层是归属方为本地运营商：IP 段挂在当地的 ISP 或宽带运营商名下，而不是挂在 AWS、Cloudflare 这类云服务商的段里。两层都满足，Netflix、TikTok、ChatGPT 这类按 IP 判定地域的服务才会把你当本地用户。

普通 VPS 的 IP 常常只满足第一层甚至一层都不满足，查询工具上直接显示“Hosting”或“Data Center”，平台一检测就把你归到机房流量里，注册被拒、内容被限的几率高很多。

再往上一档是住宅双 ISP IP：在 ASN 检测里同时被识别为 ISP 类型、归属为住宅宽带运营商，比原生 IP 更像家庭用户。做账号矩阵、电商养号的人愿意为这个多付钱。但这是概率问题，平台风控是动态的，某个 IP 段被批量滥用后一样会临时降级，没有任何服务商能保证永久解锁。Akile 目前能核到的是原生 IP 档，第三方整理的说法是它的解锁能力略逊于真正的家宽 IP，养号只能算过及格线。

顺带区分一个容易混的概念：独享 IP 说的是这个 IP 只分配给你一个用户，原生 IP 说的是 IP 的归属属性。两个维度独立，一台机器可以既独享又原生，也可以独享但挂在机房段里。

## 线路怎么选：9929、CN2 GIA、CMIN2、163 各解决什么

这些名词对应的是不同运营商的回程通道，选错了比买贵了更难受。

联通 9929 是 CUII 精品网，可以理解成联通版的 CN2 GIA，优先级高于普通骨干，回程强制走 9929 再分送给三网。电信的 CN2 GIA 是电信自己的顶级商用线路，全程走 CN2，晚高峰基本不受影响；CN2 GT 只有部分节点走 CN2，质量中等；普通 163 骨干是公共互联网，晚高峰拥堵和丢包都明显。移动这边对应的是 CMIN2、CMI 这类优化通道。

容易踩的坑是把 9929 和 CN2 GIA 当成同一家的东西。9929 归联通，CN2 GIA 归电信，两者都是优质回程但运营商不同。Akile 洛杉矶 Premium 的做法是三网各走各的优化通道，联通 9929、移动 CMIN2、电信 CN2 GIA，电信用户也能拿到稳定回程。

香港 HKBGP Plus 用的是另一套组合，电信去程走联通 AS10099、回程走电信 163，联通双向 AS10099，移动双向 CMI。这套路由对南方用户友好，延迟比洛杉矶低一截。

英国 UK Lite2 要单独说。它的 500Mbps 是国际带宽，国内方向不优化：三网平均延迟 249ms，最快的贵州贵阳联通也要 185ms，电信去程还得绕美国和德国再到英国，移动去程绕香港和日本。它适合英国本地业务、英国原生 IP 解锁，别指望拿来回国用。
